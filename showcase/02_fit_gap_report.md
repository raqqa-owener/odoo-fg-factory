# P2 — Fit & Gap Detection

## 目的

Odoo標準機能へ安全に対応付けられない参照を検出し、自動生成対象から除外します。LLMが推測で接続先を補完することを防ぐためのガードレールです。

## 判定例

| 検出対象 | Gap種別 | 判定 | 処理 |
|---|---|---|---|
| 在庫調整時の損失管理 | ambiguous reference | 未解決 | 自動生成から除外 |
| ロケーション状態管理 | ambiguous reference | 未解決 | 自動生成から除外 |
| 手直しと利用可能在庫確認 | ambiguous reference | 未解決 | 自動生成から除外 |
| 発注から受入検査への接続 | ambiguous reference | 未解決 | 自動生成から除外 |
| 品質判定の保留・解除 | ambiguous reference | 未解決 | 自動生成から除外 |
| `stock.picking.type`参照 | ambiguous reference | 未解決 | 自動生成から除外 |
| `crm.team`参照 | stub required | 未解決 | 自動生成から除外 |
| `delivery.carrier`参照 | stub required | 未解決 | 自動生成から除外 |

## 顧客・ベンダー向けメッセージの原型

> 要件は検知しましたが、処理方法または接続先を一意に確定できないため、今回のOdoo自動反映対象から除外しました。追加開発の要否と影響範囲を確認する必要があります。

## 重要な点

検出できたことと、実装できることを同一視していません。未解決項目は消さずに`report_only`として保持し、将来の顧客質問、影響範囲調査、追加開発仕様書の入力に利用する設計です。
